# Evaluador Relámpago — I.E. 82019 "La Florida del Inca"

App de evaluación formativa para 5.° Grado "E". Funciona 100% offline, sin servidor:
todo se guarda en el propio dispositivo (localStorage).

## Publicar en GitHub Pages (una sola vez)

1. Crea un repositorio nuevo en GitHub (puede ser privado), por ejemplo `evaluador-relampago`.
2. Sube estos 4 elementos manteniendo la misma estructura de carpetas:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - carpeta `icons/` completa (icon-192.png, icon-512.png, icon-512-maskable.png, apple-touch-icon.png)
3. Ve a **Settings → Pages** del repositorio → en "Branch" elige `main` y carpeta `/ (root)` → **Save**.
4. Espera 1–2 minutos. GitHub te dará una URL como:
   `https://TU-USUARIO.github.io/evaluador-relampago/`

## Instalar en el celular (Android o iPhone)

1. Abre esa URL en Chrome (Android) o Safari (iPhone).
2. Android/Chrome: aparecerá un aviso "Agregar a pantalla de inicio", o desde el menú ⋮ → **Instalar aplicación**.
3. iPhone/Safari: toca **Compartir** (el cuadrado con flecha) → **Agregar a pantalla de inicio**.
4. Quedará como un ícono más en tu celular, con el logo que compartiste, y abrirá a pantalla completa como una app normal — funciona incluso sin internet después de la primera vez que la abras.

## Cómo reutilizar preguntas sin volver a importarlas

- Cuando guardas un banco de preguntas con **"💾 Guardar preguntas"**, queda asociado al tema/estándar de esa sesión y aparece en **"📂 Evaluaciones guardadas"** la próxima vez que abras la app o busques el mismo tema — no hace falta importar el PDF de nuevo.
- Todo esto vive en el almacenamiento del navegador de tu celular. Si cambias de celular, usa la copia de seguridad (siguiente punto).

## Copia de seguridad

En la pestaña **"Copia de seguridad"** dentro de la app:
- **Descargar copia de seguridad**: genera un archivo `.json` con todo (bancos de preguntas, sesiones evaluadas, asistencia, pendientes). Guárdalo en Drive o donde prefieras.
- **Restaurar desde archivo**: sube ese `.json` en cualquier celular/navegador para recuperar todo tal cual estaba.

Se recomienda descargar la copia de seguridad al menos una vez por semana.
